## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v14 or above)
- [npm](https://www.npmjs.com/)
- [MongoDB](https://www.mongodb.com/) (for MongoDB-related modules)

### Installation

```bash
# Clone the repository
git clone https://github.com/agrajjain4786/Javascript.git

# Navigate into the project
cd Javascript

# Install dependencies
npm install
```

### Running a Module

Each folder is self-contained. Navigate to the module you want to explore:

```bash
cd ExpressDir
node index.js
```

> 💡 Some modules may have their own `package.json`. Run `npm install` inside that folder if needed.
